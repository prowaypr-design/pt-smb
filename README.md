# PT для SMB × PROWAY — файлы для Тильды

Подключаются через jsDelivr: `https://cdn.jsdelivr.net/gh/prowaypr-design/pt-smb@1.0.0/<файл>`

- `pt-smb.css` — стили сайта. Всё ограничено обёрткой `.pw`, родные блоки Тильды не задевает.
- `pt-smb.js` — меню, появление блоков, рендеры с анимацией, форма-подсказки. Нужны GSAP 3.12.5, ScrollTrigger, Lenis 1.1.13.
- `tile3d.js` + `tex.js` — движок 3D-плиток и текстуры (Ольга). Подключать только на страницах с 3D.
- `scenes.js` — сцены продуктов (`<section class="scene" data-scene="...">`).
- `blocks.js` — три блока главной: `#chain`, `#tog`, `#way`.
- `img/` — рендеры PT и логотипы.

После изменения файлов — новый релиз (тег) и замена версии в ссылках.
